# Calle Malfeitos

Un paseo por la calle Malfeitos de Guareña (Badajoz), en el navegador. Versión de prueba.

- Para andar: WASD; Mayús, correr; Espacio, saltar; el ratón gira la cámara. En el móvil, con los dedos.
- «Crea tu personaje» abre el editor de personajes.
- Los créditos y las licencias de lo que lleva dentro, en [CREDITOS.md](CREDITOS.md).

Este repositorio lleva solo lo que el navegador necesita para abrir el juego; lo monta `tools/despliegue/web.py` del proyecto.
